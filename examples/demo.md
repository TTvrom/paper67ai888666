# 从闭馆时间到留灯：一个排版样例论文

摘要：这是一份用来跑通 `make_docx.py` 的最小样例，正文本身不重要，重要的是它把全部标记都用了一遍——标题、摘要、关键词、一级标题、二级标题、带引注上标的正文、`<blank>` 空行、参考文献。跑一遍就知道输出长什么样。

关键词：样例；排版；约定式 markdown

<blank>

## 一、为什么需要一份样例

规格写在 `SKILL.md` 里就够了，但规格读起来没有形状。有人宁可先看见一张排好的纸，再回头对照规则。

这份样例一共不到六百字，两页多一点。它不证明论点，只证明脚本跑得通。

## 二、标记怎么用

### （一）标题分两级

`#` 是题目，三号加粗居中。`##` 是一级标题，`###` 是二级标题，都是四号加粗居中。

正文一行一段，不要在行内换行——脚本按行分段，手动折行会被当成两个段落。

### （二）引注写成上标

被引述的短语后面紧跟 `<sup>[1]</sup>`，例如：有研究指出<sup>[1]</sup>，引注离被引述的短语越近越好。

拖到句末也不算错，只是既不合规范，也容易被判成"空泛归因"。这条规则的细节可以看仓库里 `course-paper-zh/SKILL.md` 的"常见坑"。

## 三、生成

```bash
python course-paper-zh/scripts/make_docx.py examples/demo.md examples/demo.docx
```

读完会用 Word 的 `ComputeStatistics` 复核页数，用 `pymupdf` 把 PDF 渲成图看一眼——数字对，不代表看着顺。
