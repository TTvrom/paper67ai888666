# 降低中文文本的 AIGC 检出率

## 先摆正三件事

1. **没有通用的"AI 率"**。知网 AIGC、维普、格子达、PaperYY 各算各的，同一篇文本在这家 30%、那家 60% 是常态。所以不要承诺具体数字，只承诺"可测的痕迹降了、读感变了"。
2. **可复现的打分 ≠ 检测器读数**。用 `academic-humanizer-zh` 的 `scripts/score.py` 做**表层分**（S1–S9 词表，确定性、可复现），自己补**语义判读**（C1–C3，必须带原文证据）。两者分开报，不合成一个数。
3. **检测器吃的是困惑度与突发性，不是语法对错**。故意写病句、错别字，对分数影响很小，却直接损失评分类里的"语言流畅"。**降的是规整度，不是正确度**——这句是底线。

实测参照（一篇 2100 字中文课程论文，同一份文件）：

| 指标 | 初稿 | 定稿 |
|---|---|---|
| score.py 表层分 | 0.8% | 0.0% |
| 句长变异系数 CV | 0.580 | 0.597 |
| PaperYY AIGC 疑似率 | — | 0% |
| PaperYY 查重 | — | 10.6% |

结论：真正让检测器从"高"掉到"0"的，往往不是词表，而是**结构性打断**。

## 流程

### 1. 抽纯文本

```bash
python scripts/docx2txt.py paper.docx paper.txt   # 同时打印字数
```

`.docx` 走 zipfile + XML，不依赖 python-docx；纯文本直接跳到第 2 步。

### 2. 打分

```bash
python <academic-humanizer-zh>/scripts/score.py paper.txt --json before.json
```

记下 `ai_rate_surface`、`document.rhythm`（句长均值与 CV）、每段 `hits`。

### 3. 语义判读（这一步不能省）

表层 0% 不等于干净——**政论/宣传体是典型**：满篇四字排比和口号，一个词表都踩不中。逐项给分并引原文：

- **C1 节奏过平滑 (0–20)**：每段都以一句判断收尾；句句长而匀。
- **C2 推理扁平 (0–15)**：纯断言，无例外、无反例、无边界。
- **C3 口吻错位 (0–10)**：学术稿被写成宣讲稿；口号密集。

引用原句作证据，没有引文的扣分不计。

### 4. 改写（按效果从高到低）

**① 打断"段段工整收尾"**（最有效）
原文：`……这些军队挡不住，损失却和丢一块阵地差不多。` → 停在事实上，别补"国防的防由此扩展到了所有环节"这类总结句。

**② 插短段**
在长段之间插二十来字的独立段：`三重压力不是一般重，最硬的那条先说。`

**③ 流水句**
把列举改成逗号连缀：`……数据，二十来个，军事只是其中一个。`

**④ 口语层**（每千字 3—5 处，多了变油滑）
`十有八九`、`干脆写成了义务`、`问题就剩一句`、`不是一般重`。

**⑤ 打散对仗**
`门槛极低、后果极重` → `门槛很低，后果又重`；`A、B、C、D、E` 五项顿号 → `A、B，还有 C 和 D`。

**⑥ 补边界与反例**（专治 C2）
`这几条能撑起"有责任"，撑不起"必须做出某项贡献"`；`硬说每个专业都是战位，反而假`。

**⑦ 指代不精确**
`那张表`、`那一段`、`这条边界`——人本来就不精确。

**⑧ 去掉二分升华框**
`不是A而是B`、`不仅…而且`、`与其说…不如说`。这类句式是中文 AI 腔最稳定的反射，一段里出现两次就是模板。

### 5. 复测

```bash
python <academic-humanizer-zh>/scripts/score.py paper.txt --json after.json \
  --compare before.json --semantic semantic.json --report 对比报告.md
```

`semantic.json` 格式：`{"note": "...", "before": {"C1":[分,"证据"],...,"composite":"中"}, "after": {...}}`。
**某段改了分数不降反升，回去重改那一段**——多半是把一个触发词换成了同类词。

### 6. 回归检查（最容易漏）

| 检查 | 命令/做法 | 为什么 |
|---|---|---|
| 字数 | `docx2txt.py` 报正文纯文字 | 改写常把字数改掉，用户对字数是硬的 |
| 分页 | Word COM `ComputeStatistics(2)` | 删几十个字会改分页，末页只剩一两行很难看 |
| 格式 | 读回字号/行距 | 重排时容易把固定行距写成单倍 |
| 读感 | 导出 PDF，`pymupdf` 渲染成图看一遍 | 数字对不代表看着顺 |

## 反模式

- ❌ 写病句、错别字、错标点冒充人类——扣"语言流畅"分，且一眼假
- ❌ 把所有段落都改成口语——那是另一种均匀
- ❌ 只删触发词不改结构——换完词读着还是提纲扩写
- ❌ 动事实、数据、法条、引用——降 AI 不许改真的东西
- ❌ 每段都加"值得注意的是/说白了"——新的模板替代旧的模板

## 判停条件

满足以下三条就停手，别为了数字继续拆：

1. 表层分 ≤ 5%、句长 CV ≥ 0.55、段长有明显的长短交替
2. 语义上 C1/C2 都有对应的结构性改动作证据
3. 通读一遍不会在某句上卡住

还想再低，最有效的一步不是改语法，是**往里放只有作者写得出来的东西**：具体课号、具体日期、具体场景、一次真实对话。这类内容困惑度天然高，检测器判不成机器。

## 目录

- `scripts/docx2txt.py` — docx → 纯文本 + 分节字数
- `scripts/rhythm_check.py` — 句长/段长变异、句首重复、四字串重复（检测器真正吃的东西）
- 打分与报告生成复用 `academic-humanizer-zh/scripts/score.py`
