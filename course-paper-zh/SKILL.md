# 中文课程论文：从命题说明到定稿

## 这个技能解决什么

老师给的那份"命题说明"里，评分标准、字数、格式、提交方式全都写着。多数人只读了题目，剩下全凭感觉，然后丢的正是那 20—30 分的"格式"和"结合现实"。

本技能把那份文件当成施工图：**每个评分项先找到对应的段落，再决定写什么**。

## 硬规则

1. **不自作主张改主题**。老师定的主题词必须原样出现在标题和正文引用里；标题自拟，但要显式包含主题词与所用理论名，否则被判"与主题无关"（常见后果：总分低于 20）。
2. **只锚定一个理论**。评分项写"围绕某个理论"就写一个，写三个等于没有。
3. **不编造**。文献的作者/刊名/年期/页码、法条的条号、事件的日期，查不到就不写这条。参考文献里出现 `XX`、`主编.`、`出版地: 出版社` 这类占位符，等于向老师声明"这稿没检查"。
4. **改字数就重排页**。任何增删之后都要复核页数，末页只剩一两行时，宁可再删一句把它压回去。
5. **不留空话**。"具有重要意义""随着时代的发展""综上所述"，评分项里的"语言流畅"就是被这几句扣掉的。

## 流程

### 1. 读要求原件，拆成一张表

.doc 是老格式，文本工具读不了，用 Word COM：

```powershell
$w = New-Object -ComObject Word.Application; $w.Visible = $false
$d = $w.Documents.Open($path, $false, $true)
$d.Content.Text
$d.Close([ref]0); $w.Quit()
```

读出来先做一件事：把**评分要素**逐条抄成表，和**字数、格式、提交方式**并列。这张表决定了后面每段写多少字、每个论据该放哪。

典型映射（军事/思政课常见）：

| 评分要素 | 谁去接 |
|---|---|
| 紧扣主题、围绕某理论（20） | 标题 + 第二节 |
| 理论分析准确（20） | 第二节点材料，给时间、会议、条文号 |
| 结合时代背景/社会需求（30） | 第三节，全篇最重，必须具体年份＋具体领域＋具体场景 |
| 字数（10） | 按目标字数 ±10% 排版 |
| 条理语言（10） | 层次序号不混用，少套话 |
| 格式（10） | 见第 6 步 |

### 2. 定题

给 1 个主推 + 2 个备选，并说明风险。主推题目的合格标准：

- 主题词齐全（如"新时代大学生国防责任担当"七个要素都在）
- 理论名可见（"总体国家安全观视域下"这类）
- 有一个能被 1500 字撑住的小切口

**别用**只有主题词、没有理论落点的题目。

### 3. 搭论证链，不搭提纲

写一句推导出来，每一节的开头要能由上一节结论推出：

> 理论的关键概念 → 这个概念的推论 → 推论在现实里的三重压力 → 落到个人可执行的动作

反面是"理论—现实—对策"三段并列，每段各写三条，等长收尾——老师和检测器都认得出。

篇幅刻意不等分（如 180 / 380 / 450 / 470 / 160）。

### 4. 理论先想明白，再写

给自己的理解版用大白话写一遍（不写进稿），再改写成书面语底稿。两个版本都留着，前者防止把理论写成术语堆砌，后者防止照抄官方表述撞查重。

### 5. 核证材料

- **法条**：精确到条号，抄原文关键词。"应当"不能写成"可以"，"共同责任"不能写成"重要责任"。
- **文献**：四要素齐全（作者、刊名、年(期)、起止页码）。页码去知网条目页或期刊官网抄，**不猜**。
- **文献类型标识**：先看老师给的范围（常见 M/C/N/J/D/R/S/P 八类）。`[Z]` 虽在 GB/T 7714 里，但若老师只列八类，法规改走 `[N]`（报纸刊载版，带日期与版次）。
- **事件**：日期、地点、名称逐字核。用权威站点（gov.cn、news.cn、npc.gov.cn）。

### 6. 生成 docx

用 `scripts/make_docx.py`。输入是一个按约定写的 .md：

```markdown
# 题目（三号加粗居中）

摘要：……
关键词：A；B；C

## 一、一级标题
### （一）二级标题
正文段落……引用处写 <sup>[2]</sup> 即上标
> 灰色提示行（可删）

<blank>

[1] 参考文献条目
```

命令行：

```bash
python scripts/make_docx.py paper.md paper.docx
```

默认按中文课程论文的常见要求排版：标题三号加粗居中、小标题四号加粗居中、正文小四宋体＋西文 Times New Roman、行距固定 25 磅、首行缩进 2 字符、A4。可用 `--line 30` / `--body 10.5` 等参数改。一级/二级标题自动带 `keepNext`，不会孤零零掉在页脚。

### 7. 校验（必做）

数字读回一遍，不要只看文件生成了：

```powershell
$w = New-Object -ComObject Word.Application; $w.Visible = $false
$d = $w.Documents.Open($doc, $false, $true)
"pages: " + $d.ComputeStatistics(2)
$p = $d.Paragraphs(1).Range
$p.Font.NameFarEast; $p.Font.Size; $p.Font.Bold
$d.Close([ref]0); $w.Quit()
```

- 行距"固定值 25"读回是 `LineSpacingRule = 4`（wdLineSpaceExactly）、`LineSpacing = 25`
- 页数要复核。末页只剩 1—2 行时，删一句把它压回去；或去掉参考文献前那一行空行
- 渲染成图人眼看一遍：`pymupdf` 打开导出的 PDF，`page.get_pixmap(dpi=140).save(...)`
- Word COM 会偶发卡死。卡住就 `job_kill`，改用上次导出的 PDF 复制，别反复重试

### 8. 交付清单

按命题说明逐项报一遍：命名（学号+姓名+题目）、查重报告命名、打印要求（封面单面/正文双面）、装订（几颗钉）、提交口与截止周次。

## 常见坑

| 现象 | 原因 | 处置 |
|---|---|---|
| 末页只剩一两行 | 正文增删后没复核分页 | 删一句或去掉文献前空行，压回整数页 |
| 二级标题和一级撞脸 | "小标题居中四号加粗"被字面执行到两级 | 按老师原话做，但主动提示：二级改左对齐缩进更耐读 |
| 参考文献里出现占位符 | 教材信息没拿到 | 直接删掉这条，四条足够；要加就把版权页信息要全 |
| 字数和 Word 显示差一截 | Word 把摘要/参考文献/标点都算进去 | 报数时分开报：正文纯文字（含标点/不含标点）、摘要、参考文献 |
| 老师要"1500 左右"，写到 2100 | 只看到"以上"两个字 | 命题写"左右"就控制在 +20% 以内，超了要主动问用户压不压 |
| 一级标题落在页脚、正文从下页起 | 标题没设 keepNext，段前位移刚好卡在页底 | 脚本已默认加 `keepNext`；手排的稿子在标题段落上勾"与下段同页" |
| 句末才挂 `[2]`，前文写"有学者指出" | 引注离被引述的短语太远 | 改成"有学者指出<sup>[2]</sup>，……"。既合规范，也不会被 AIGC 检测判成"空泛归因"（该规则要求引注在 ±30 字内） |
| 段末只剩一两个字 | 段长刚好比整行多出几字 | 从该段删掉与余字等量的字数（删 2 字就少一行）；或改一句让长度凑整 |

## 目录

- `scripts/make_docx.py` — 约定式 markdown → 格式合规 docx（纯标准库，无依赖）
- `scripts/docx2txt.py` — docx → 纯文本（含字数统计），供复核与检测
